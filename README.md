# UE Campus Portal
Smart Campus Classroom Availability & Indoor Navigation Portal — University of Europe for Applied Sciences.
React 18 + TypeScript + Vite.

    npm install && npm run dev

- Floor-plan coordinates: edit `src/data.ts` (ROOMS, STARTS).
- Timetable and sample matriculation numbers: `src/data.ts`.
- QR wayfinding: `?from=entrance|reception|stairs`.
- Deploy: `vercel` (framework preset: Vite).
